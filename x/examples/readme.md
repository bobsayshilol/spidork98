# Examples

Here's all the experiments, in the order they were made:

## `libpc98`

Library for abstracting away the PC-98 hardware.

Also contains tools for converting ordinary formats into those usable by `libpc98`.

## `basic`

Basic example that should work on PC-98 and PC-AT hardware.

## `bgm`

PC speaker test.

## `gfx`

Graphics mode test.

## `fire`

Reproduction of the classic demoscene fire effect.

Too much time spent optimising this...

## `bench`

A set of benchmarks for trying out different optimisations.

Only ran in the emulator so the results might be completely bogus.

## `pcm`

Proper PCM audio test.

## `mouse`

Mouse input test.

`dosbox-x` has a quirk in how it handles mouse input, so you may need to enable `MOUSE_BROKEN_CURSOR_LOCK`.

## `ayylmao`

ayylmao

## `demo`

A demo of all the moving parts fitting together.

## `sound`

Sound system test.
